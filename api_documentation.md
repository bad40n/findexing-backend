# Findexing Backend API & Database Schema Documentation

Welcome to the **Findexing** backend API documentation. The backend server runs on `http://localhost:5002` by default.

---

## 1. Database Schema Design (MongoDB / Mongoose)

### **User Schema** (`User` Collection)
| Field | Type | Validation / Defaults | Description |
|---|---|---|---|
| `_id` | ObjectId | Auto-generated | Unique identifier for the user account |
| `name` | String | Required | Full name of the user |
| `email` | String | Required, Unique | Valid email address |
| `pass` | String | Required | Hashed password |
| `currency` | String | Required, Default: `"BDT"` | Active currency symbol or code (e.g. `USD`, `EUR`, `BDT`) |
| `type` | String | Enum: `["admin", "user"]`, Default: `"user"` | User security roles |
| `isActive` | Boolean | Default: `true` | Indicates if account is active |
| `createdAt` | Date | Autogenerated | Timestamp of creation |
| `updatedAt` | Date | Autogenerated | Timestamp of last edit |

### **Transaction Schema** (`Transaction` Collection)
| Field | Type | Validation / Defaults | Description |
|---|---|---|---|
| `_id` | ObjectId | Auto-generated | Unique identifier for the transaction |
| `userId` | ObjectId | Required, Ref: `"User"` | ID of the account owner |
| `type` | String | Required, Enum: `["income", "expense"]` | Type of log |
| `amount` | Number | Required, Positive | Financial amount |
| `category` | String | Required | Category slug (e.g. `food`, `transport`, `shopping`) |
| `title` | String | Required | Transaction description/title |
| `note` | String | Optional | Add-on notes/comments |
| `date` | Date | Required, Default: `Date.now` | Date of transaction |
| `currency` | String | Required, Default: `"BDT"` | Currency code of transaction |

### **Budget Schema** (`Budget` Collection)
| Field | Type | Validation / Defaults | Description |
|---|---|---|---|
| `_id` | ObjectId | Auto-generated | Unique identifier for the budget |
| `userId` | ObjectId | Required, Ref: `"User"` | ID of the account owner |
| `categoryId` | String | Required | Category slug (e.g. `food`, `transport`) |
| `limit` | Number | Required, Positive | Maximum monthly spending allowance |
| `period` | String | Enum: `["monthly"]`, Default: `"monthly"` | Budget cycle duration |

*(Note: Budget schema enforces a unique compound index on `{ userId, categoryId }` to ensure one budget configuration per user category).*

## 2. API Reference

All requests that require authentication must supply the token in the headers as:
`Authorization: Bearer <JWT_TOKEN>`

### 2.1 User Authentication & Profile (`/api/user`)

#### **Register User**
* **Method**: `POST`
* **Path**: `/api/user/register`
* **Request Body**:
  ```json
  {
    "name": "Rahim Uddin",
    "email": "rahim@example.com",
    "pass": "password"
  }
  ```
* **Response (201 Created)**:
  ```json
  {
    "status": "success",
    "message": "User registered successfully",
    "data": {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "user": {
        "_id": "60d0fe4f5311236168a109ca",
        "name": "Rahim Uddin",
        "email": "rahim@example.com",
        "currency": "BDT",
        "type": "user",
        "isActive": true,
        "createdAt": "2026-07-11T21:55:00.000Z",
        "updatedAt": "2026-07-11T21:55:00.000Z"
      }
    }
  }
  ```

#### **Login User**
* **Method**: `POST`
* **Path**: `/api/user/login`
* **Request Body**:
  ```json
  {
    "email": "rahim@example.com",
    "pass": "password"
  }
  ```
* **Response (200 OK)**:
  ```json
  {
    "status": "success",
    "message": "User logged in successfully",
    "data": {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "user": {
        "_id": "60d0fe4f5311236168a109ca",
        "name": "Rahim Uddin",
        "email": "rahim@example.com",
        "currency": "BDT",
        "type": "user",
        "isActive": true
      }
    }
  }
  ```

#### **Get Logged-in User Profile (Me)**
* **Method**: `GET`
* **Path**: `/api/user/me`
* **Auth**: Required
* **Response (200 OK)**:
  ```json
  {
    "status": "success",
    "data": {
      "_id": "60d0fe4f5311236168a109ca",
      "name": "Rahim Uddin",
      "email": "rahim@example.com",
      "currency": "BDT",

      "isActive": true

  ```

#### **Update User Profile**

        "type": "expense",
        "amount": 350,
        "category": "food",
        "title": "Lunch at Restaurant",
        "note": "With colleagues",

### 2.3 Budgets (`/api/budget`)

#### **Fetch All Category Budgets**
* **Method**: `GET`
* **Path**: `/api/budget`
* **Auth**: Required
* **Response (200 OK)**:
  ```json
  {
    "status": "success",
    "data": [
      {
        "_id": "60d0fe4f5311236168a109cd",
        "userId": "60d0fe4f5311236168a109ca",
        "categoryId": "food",
        "limit": 5000,
        "period": "monthly"
      }
    ]
  }
  ```

#### **Set or Update Category Budget**
* **Method**: `POST`
* **Path**: `/api/budget`
* **Auth**: Required
* **Request Body**:
  ```json
  {
    "categoryId": "transport",
    "limit": 2500
  }
  ```
* **Response (200 OK)**:
  ```json
  {
    "status": "success",

      "_id": "60d0fe4f5311236168a109ce",
      "userId": "60d0fe4f5311236168a109ca",
      "categoryId": "transport",
      "limit": 2500,
      "period": "monthly"
    }
  }
  ```
